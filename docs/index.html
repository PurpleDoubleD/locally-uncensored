Ask anything and you get an answer instead of a lecture. Show it a photo, drop in a PDF, and it remembers what matters across chats. Ask for a picture and it draws one right in the conversation. The app finds and installs the right free model for your PC, so all you do is type.

New in 3.0.1

One model draws and edits, and Linux stops tripping itself.

3.0.1 is a correctness release with two additions. Qwen-Image 2.1 makes a picture from a prompt and edits one from a reference image, on your own card, on Windows and Linux. LoRAs get a tab of their own in Models. On the fixing side: a graphics card whose free memory could not be measured is planned more carefully instead of optimistically, the Linux AppImage stops handing its own runtime to every program LU starts, and the local engine answers one conversation at a time and says how many are waiting. Free as always, and the app updates itself.

CREATE

Qwen-Image 2.1, generating and editing in one model

Write a prompt and get a picture, or add a reference image plus a prompt and edit one, with no mask to paint. It appears in the Generate picker and the Edit picker like any other installed image model. The bundle pulls about 16 GB across three files and needs ComfyUI 0.37.0 or newer; an older ComfyUI is told which version to update to first. One reference image at a time, and no painted masks, because the encode node it runs on takes neither.

Windows and Linux. Research license, no commercial use
MODELS

LoRAs have a tab of their own

Get searches CivitAI and downloads what you pick straight into ComfyUI's loras folder. Installed lists what is on disk with its size, marks a character you trained yourself with its trigger word, and deletes a file you no longer want. Before this they sat unnamed among the checkpoints in the Image tab. In Create, a character LoRA now offers only the models trained for that character's family, so the picker cannot suggest a pairing that would fail.

Windows and Linux, where ComfyUI keeps that folder
FIXED

A card that cannot report free memory is planned carefully

When no free VRAM reading was available, a graphics card used to be planned as if the whole card were sitting empty, and the log said "N MiB are free" for a number that was really the total size, other programs included. That weaker reading now gets a bigger safety margin and is logged as total capacity, so a start places fewer layers rather than too many. The engine also picks its processor code path at startup, so a machine without AVX2 runs local models instead of exiting straight after start, and says which instruction set is missing when it cannot.

Windows and Linux
FIXED

The Linux AppImage keeps its runtime to itself

git, a system Python, pip, ffmpeg, nvidia-smi, the coding agent shell and everything the Character Trainer starts no longer inherit the AppImage runtime's own library and Python variables. That inheritance made a perfectly healthy system Python fail to find its own standard library, and the diagnosis pointed at the wrong thing. On a distribution where pip refuses to write into the system Python, the isolated environment LU already built survives the first pip call, and the Coding Agent's terminal no longer picks up the same broken environment.

Linux, AppImage and packages
CHAT

One local conversation at a time, and it says so

The local model answers one chat at a time. A chat that has to wait now says so, with a line showing how many are ahead of it, and Stop works while it waits and takes it out of the line. Stop, signing out and quitting reach every conversation, not only the one on screen. Temperature, Top P and Max tokens belong to the conversation you moved them in instead of every open chat sharing one value from Settings, and a field nobody moved is left out of the request so the model applies its own default.

Local engine, every platform that has one
CLOUD

Clip lengths that the picked model really has

A cloud video render now offers exactly the lengths the chosen model supports, read from the live catalog, instead of the same fixed pair for every model. A render started without a prompt, a presenter reading a script for instance, gets a real name in the gallery instead of an empty tile. The catalogue itself is unchanged in this release, and so is the content policy setting in your LU Cloud account: Strict, Standard, or off. It applies to cloud image and video.

Questions

Common questions.

What is Locally Uncensored?

A free, open-source local AI studio for your desktop. Install it like any normal app and you're chatting, generating images, and making videos in minutes, with no command line and no Docker. Under the hood: chat with 20+ provider presets, a coding agent, image generation via ComfyUI (FLUX 2, Juggernaut XL, Z-Image, SDXL), and video generation (Wan 2.1, HunyuanVideo, LTX 2.3, FramePack F1) in one interface. AGPL-3.0 licensed.

Does it support Qwen 3.8, GPT-OSS and GLM-4.7?

Yes. Qwen 3.8 27B is in the Model Manager since v2.6.6, and vision works: the image tower comes as a separate mmproj file that the download writes next to the model. Official, abliterated and uncensored builds, plus a 9B distill for small cards. GPT-OSS-120B and GPT-OSS-20B run via Ollama. GLM-4.7 Flash supported through Ollama. Also ready: DeepSeek R1, Llama 4, Gemma 4, Mistral Small 3, Phi 4.

Can I use it as a ChatGPT or Claude alternative?

Yes. Locally Uncensored works as a ChatGPT and Claude alternative that runs on your own hardware. Use Qwen 3.8, GPT-OSS, GLM-4.7, DeepSeek R1, Llama 4 or Gemma 4 instead, or add cloud providers (OpenAI, Anthropic, OpenRouter, Groq) alongside the local stack.

Is it really free and offline?

Yes. After setup and model download, no internet is needed for the local providers. No accounts, no telemetry, no usage limits. Cloud providers are optional, and the core runs one-hundred percent on your hardware.

How is this different from Open WebUI or LM Studio?

Those tools handle text chat. Locally Uncensored adds a coding agent with fourteen MCP tools, image generation, video creation, A/B model comparison, local benchmarking, granular permissions, file upload with vision, and thinking mode, all in one app.

What hardware do I need?

Text chat: 8 GB RAM. Image generation: an NVIDIA card from 6 GB of VRAM with the starter checkpoint, 8 to 10 GB for FLUX. Video generation: from 6 GB for AnimateDiff and image to video with FramePack F1, from 8 GB for the Wan 2.1 starter, 12 GB and up for Wan 2.2 and HunyuanVideo. The app auto-detects hardware and recommends models. Windows 10/11 and Linux supported.

What does "uncensored" mean?

Abliterated models with artificial restrictions removed. The AI responds honestly without refusing or adding disclaimers. Combined with local execution, your conversations stay private.

Does remote access leak data?

Only if you explicitly dispatch a chat over LAN or Cloudflare Tunnel. Remote is opt-in, gated behind a six-digit passcode, and you see exactly when a device is connected. No background uploads. No telemetry.

Can I use this on macOS?

No. There is no Mac build and there has never been one. The release workflow builds Windows and Linux. On a Mac, use the hosted studio in a browser at lu-labs.ai.

What the agent does

There are two places to run it, and one more way to use the same idea in chat.

  • In the browser. The Code tab on LU Cloud works on a GitHub repository you connected. You choose which repositories it can see. Changes only arrive as pull requests, and you decide what to merge.
  • On your PC. The desktop app runs the agent on folders on your own machine. Edits across several files are shown as diffs you approve. Commands and tests run in a sandbox. When you run a local model, your code never leaves the computer.
  • Agent mode in chat. It also plans tasks and calls tools step by step, for work that is not tied to a repository.

Which models it runs on

LU Cloud runs the agent on 40 open chat models, and all of them can call tools. You pick the model per task. A cheap model is fine for a small fix. A large model is worth its price when the change touches many files or needs careful reasoning.

On your PC the agent uses the model you install. How large that model can be depends on your graphics card.

Where uncensored fits for coding

Most code is not sensitive. Any capable model will write a form validator or a database migration. The word uncensored matters at the edges, where cautious assistants refuse work that is legitimate. Typical cases:

  • Security research on your own systems. A scanner for your own network, a test of your own login against brute force, a proof of concept for a bug you found in your own code.
  • Reverse engineering for interoperability. Reading a binary or a protocol so your software can talk to it. We wrote about this in local AI for reverse engineering and in reverse engineering an app with a local model.
  • Malware analysis in a lab. Unpacking and explaining a sample on an isolated machine, and writing detection rules for it.
  • Adult game modding. Mods for games with mature themes, where some assistants refuse to touch the project at all.

On LU Cloud, hosted text has no extra filter from LU. The models themselves differ. Some were trained to decline more than others, and no model writes everything you ask. If one refuses a legitimate task, try another from the picker. The No Filter mark comes from a writing test, not a coding test, so treat it as a hint: 13 of the 36 cloud chat models we measured answer in full without refusing, and only those carry the No Filter mark.

Illegal use stays illegal. Attacking systems you do not own or spreading malware is not what this is for, and the Terms of Service apply.

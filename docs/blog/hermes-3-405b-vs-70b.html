Hermes 3 405B vs Hermes 3 70B: Which One, When

Short version, because most comparisons bury it: Hermes 3 70B is the default and Hermes 3 405B is the model you switch to for a hard prompt. If you take nothing else from this page, take that. The rest is the reasoning, and the numbers that make it true.

What stays the same

Both are Nous Research fine tunes of the same Llama 3.1 family. That matters more than the parameter count does for how the model feels to use. They share the same instruction-following character: they follow a system prompt closely, they stay in a persona you hand them, and they do not lecture you back at the end of an answer. Swapping between them mid-project does not force you to rewrite prompts, which is not something you can say about jumping between different labs.

Neither has a thinking mode. There is no think toggle on either, no reasoning parameter to send, and no hidden deliberation pass inflating your output tokens. Both answer flat. In the same hosted catalog, Qwen 3.6 35B A3B is the one with vision and a think toggle if you want a model that reasons before it speaks.

What changes with size

The 405B holds more in its head. On a prompt with a lot of interacting constraints (a long spec, a tangled function, a scene with six characters and a rule about who knows what), it drops fewer of them. That is the honest description of the gap, and it is real. It is not a personality upgrade, it is a robustness upgrade on hard inputs.

What it is not: two or three times better. Nothing in this business scales like that. On an ordinary turn, an ordinary summary, an ordinary bit of dialogue, you would struggle to pick the 405B blind.

The token price is the actual decision

Everything above is a small effect. The price gap is a large one, and that is what should drive your choice.

The concrete anchor: Hermes 3 70B costs 0.07 credits per output token, and the 5 EUR credit pack is 165,000 credits, which works out to roughly 2.3 million output tokens. That is a lot of roleplay. A 405B model is a different weight class on the meter, so the same money buys a fraction of that. Current per model rates are listed next to each model on the LU Labs pricing page.

Which means the two models fail differently. A hundred-turn roleplay session or an agent loop hammering tools is a token volume problem, and volume problems are won by the cheaper model. A single gnarly refactor is a quality problem, and you should not be counting credits on it. Same account, same picker, one click apart. The mistake is picking one and staying there out of habit.

The local escape hatch, and where it closes

We ship a free open source desktop app for Windows and Linux, and it runs whatever you install, with nothing in the middle. So it is fair to ask whether you need a hosted endpoint at all.

For a 70B class model: reachable. A big workstation with enough VRAM at a low quant will run it, slowly but genuinely. Our local setup guide for Qwen 3.6 covers the quant math that applies here too, and the 2026 model roundup covers what else is worth downloading.

For 405B: closed. At 4-bit the weights alone are roughly 200 GB. There is no consumer card, and no realistic single workstation, that gets you there. If you want 405B, you want somebody else's GPUs. That is the whole argument for the hosted route, and we would rather state it plainly than pretend a home build is around the corner. The setup for both routes is in the Hermes 3 405B online guide.

Where the rest of the catalog fits

There are 15 hosted chat models, and Hermes is not always the right family:

  • Euryale 70B and MythoMax 13B: different writing voices for fiction and roleplay. Try them before assuming Hermes is the answer.
  • Lunaris 8B: the cheapest place to test a character card or a system prompt before you spend real tokens on it.
  • Qwen 3.6 35B A3B: vision and a think toggle. The one to reach for when the prompt needs an image read or actual step-by-step reasoning.
  • Qwen3 Coder 480B: code specific, and the better first choice for a coding agent than either Hermes.
  • Kimi K3: the other very large generalist. Worth a side-by-side on your own hard prompt.
  • Qwen 3.6 27B: Pro and Max tiers only, so it is not on the table with a credit pack.

The verdict

Run Hermes 3 70B. Keep credits in reserve. When a prompt comes back wrong twice in a row and the problem is clearly that the model lost track of the input rather than that your prompt is bad, switch the picker to 405B for that one message and switch back. Treating 405B as a permanent upgrade is how a 5 EUR pack becomes a weekend.

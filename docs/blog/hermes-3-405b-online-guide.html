Hermes 3 405B Online: Browser Studio and API Key Setup

We build a desktop app whose whole point is running models on your own machine, so it costs us something to write this: Hermes 3 405B is not a model you run at home. At 4-bit the weights alone are around 200 GB. That is not a big card away, it is an order of magnitude away from a 24 GB RTX 4090, and it is past most single workstations too once you add a KV cache and a real context window. Multi GPU servers can host it. A gaming PC cannot.

So for almost everybody the honest answer is a hosted endpoint. This guide covers the two routes we run: chatting with Hermes 3 405B in the browser, and pointing your own tools at it with an API key. If you want the smaller model instead, we compare them in Hermes 3 405B vs Hermes 3 70B, and the local side of the house is covered in how to run Qwen 3.6 locally.

Route 1: the browser Studio

LU Labs Cloud is the hosted layer from the same team that ships Locally Uncensored. It runs in a browser tab, which also makes it the working answer on a Mac, since there is no native Mac build of the desktop app.

  1. Open lu-labs.ai and sign in. Nothing to install, no driver, no GPU on your side.
  2. Open the chat model picker above the input and select Hermes 3 405B. It sits in a catalog of 15 hosted chat models next to Hermes 3 70B, Euryale 70B, Lunaris 8B, MythoMax 13B, Qwen3 Coder 480B and Kimi K3.
  3. Put credits on the account. A credit pack needs no subscription and starts at 5 EUR for 165,000 credits. Prices are on the pricing page.
  4. Type. There is no think toggle to worry about on this model: Hermes 3 405B has no thinking mode, so it answers directly instead of writing a reasoning pass first.

That is the whole browser path. The rest of this post is for people who want the model inside their own client.

Route 2: an API key

  1. Sign in to your LU Labs account and go to Settings > Cloud API keys.
  2. Create a key. It carries an lu_ prefix and is shown once. Copy it before you close the dialog. If you lose it, delete the key and make a new one.
  3. Point your client at base URL https://lu-labs.ai/api/inference/v1.
  4. Use the OpenAI chat completions shape and the model id NousResearch/Hermes-3-Llama-3.1-405B.

A request you can paste into a terminal right now:

curl https://lu-labs.ai/api/inference/v1/chat/completions \
  -H "Authorization: Bearer $LU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "NousResearch/Hermes-3-Llama-3.1-405B",
    "messages": [
      {"role": "user", "content": "Rewrite this paragraph in a colder register."}
    ]
  }'

The same thing with the official OpenAI Python SDK, which needs no LU specific library:

from openai import OpenAI

client = OpenAI(
    api_key="lu_your_key_here",
    base_url="https://lu-labs.ai/api/inference/v1",
)

resp = client.chat.completions.create(
    model="NousResearch/Hermes-3-Llama-3.1-405B",
    messages=[{"role": "user", "content": "Draft three openings for a heist scene."}],
)
print(resp.choices[0].message.content)

What it costs

Billing is in credits, and 1 credit is $0.00001. Two ways to get them:

  • Credit packs, no subscription. 5 EUR gives 165,000 credits, 10 EUR gives 350,000, 25 EUR gives 900,000. Any pack works from the first purchase and credits never expire.
  • The Hosted plan. 19 EUR a month with 900,000 credits, plus 2 LoRA trainings a month, which packs do not include.

For a concrete sense of scale, take the cheaper sibling: Hermes 3 70B costs 0.07 credits per output token, so a 5 EUR pack is roughly 2.3 million output tokens on it. A 405B model is a different weight class and burns faster, which is exactly why many people keep 70B as the daily driver and reach for 405B on the hard prompts. Current per model rates sit next to each model on the pricing page.

Agents and tool calls

Hermes 3 405B does not ship a native function calling head, so tool calls run through a prompt transport: the tool schema goes into the prompt and the reply is parsed back out. It is less elegant than a native path and it works, which means the Agent and the coding agent both run on this model. If your loop is long and full of tool calls, watch the token bill rather than the wall clock.

The desktop app still matters

The free, open source app for Windows and Linux (AGPL-3.0) has a Cloud switch that uses the same LU Labs account. Run a 12B or a 27B locally for the private everyday work, flip the switch when you want 405B behind the same chat window, flip it back. It is one app and one account, not two workflows. Our comparison of that setup against the usual suspects is in LM Studio alternatives, and the broader field is in best local AI apps 2026.

Honest limits

  • Shared hardware. Managed H100, A100 and B200 class GPUs, shared across users, so at busy hours you can sit in a short queue. A dedicated box would not do that. It would also not cost 5 EUR.
  • Curated catalog. 15 chat models, no bring-your-own checkpoint. If your workflow depends on a specific community fine tune nobody else asked for, local is your route.
  • Privacy. Accounts and billing are in the EU. No training on your prompts, never sold. Hosted text models answer as they were trained and we add no moderation layer on top of them. Image and video follow the Terms of Service and the prompt is checked before it renders. Content involving minors is refused everywhere, always.
  • No thinking mode. On a genuinely hard reasoning prompt, a smaller model with a reasoning pass sometimes beats 405B answering flat. Qwen 3.6 35B A3B in the same catalog has vision and a think toggle if you want to test that.

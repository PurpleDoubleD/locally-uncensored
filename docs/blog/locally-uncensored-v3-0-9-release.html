v3.0.9: LFM3 for Small Machines, Group Chats with the Full Context, and End Images in Animate

Locally Uncensored 3.0.9 came out on November 5, 2026. Liquid's LFM3 models bring text, pictures and speech to machines with little memory, and the LU Engine moves to llama.cpp b11960 for them. A group chat now sends every speaker the context you picked. Animate takes an end image and reference pictures, local videos run up to 15 seconds, and the trainer learns a style next to a character.

Most of the requests in this release came from the Discord and from GitHub issues. Most of it was clicked through in builds made like the release on a Mac, and a test build ran on Windows with an RTX 3060. What has only run in automated tests is listed at the end of this post.

The short version:

  • Liquid LFM3 for small machines: a 1.7B text model and three 2B models for pictures and speech, on the LU Engine, Ollama or MLX on a Mac
  • Group chats send every speaker the context you picked, can redo one speaker, and let you set who speaks when
  • A compaction is one quiet line, and the conversation before it stays one click away
  • Animate takes an end image and, with MiniMax H3, up to nine reference pictures. Krea 2, Qwen-Image 2.1 and FLUX.2 take reference pictures in Create
  • Local videos up to 15 seconds that keep the colours of the first section, and a rough preview while a video renders
  • Train a style, a concept or a pose next to a character (Beta)
  • "Use this model" on Hugging Face opens the download in LU, and a model from the search comes in a quant that fits your graphics card
  • A status menu in the Mac menu bar and the Windows and Linux tray, and a Linux AppImage that starts again

LFM3 for small machines, and a newer engine

Liquid's LFM3 family is small on purpose. LFM3 1.7B is a text model of about 1 GB, with a thinking part and tool calls. LFM3-VL 2B reads pictures, LFM3 Audio 2B hears and speaks, and LFM3 Omni 2B does both. All four run in the LU Engine as GGUF files and through Ollama 0.40.13 or newer, and on a Mac as MLX builds. The text and picture models also run in LM Studio.

  • Speech with the same small model. LFM3 Audio and LFM3 Omni can take over dictation and read aloud, in the chat and in the Voice area, through the LU Engine or Ollama. The setting is under Settings, Voice & Remote, Speech
  • Honest about the size. Every LFM3 tile says that a model this small is good for quick answers, pictures and speech, and that a model of 7B or more does more in long chats and agent work
  • The license on the tile. The LFM Open License allows commercial use only below a revenue limit of $10 million a year, and each tile says so
  • LM Studio. Below runtime 2.65.1, LU says the runtime is too old instead of failing without a word

The LU Engine now runs llama.cpp b11960 (v0.8.0) instead of b9949, the first version that loads LFM3. LU passes the new memory loading option, keeps the thinking level where the template expects it, and a test checks that every option LU sends exists in the pinned version. An empty placeholder file is no longer taken for the engine (issue 207). The onboarding's "Models you already have" now lists the LU Engine's models too, each with the engine that runs it.

Group chats with the full context

  • Every speaker gets the context you picked (issue 201). A local model with a 256K window got about 128K of the conversation, because the group chat used the agent's trimming rule. Each speaker now gets its chosen window minus room for the answer. When older messages no longer fit, a grey line above the answer says how many were not sent to that speaker. The chat itself keeps them
  • Regenerate one speaker (issue 199). Regenerate on a speaker's answer asks only that speaker again. If later speakers already answered, LU asks whether to keep their answers or regenerate from there. The old answer stays as a version, and "Regenerate whole round" is its own button
  • Speaking order and skipping (issue 200). Plugins, Group chat lists the order with arrows and drag. A bar above the message field shows the next round, and a click lets a member sit out one round. During a round you can skip a speaker or stop the round, and what a skipped speaker already wrote stays

A tidier chat

  • Compaction is one line. Instead of a long notice the chat shows, for example, "Compacted, 11.6K → 7.1K". Small marks at the left edge open the conversation as it was before each compaction, read only, until you go back or send. A compaction never deleted anything; now you can see that
  • Recall older messages (issue 205, off by default). After a compaction LU can bring back up to four older messages closest in meaning to your new one, word for word. The search runs on your machine with the bundled embeddings server or a local Ollama
  • Preview HTML the model writes. A code block with a page gets a Preview button. The page runs in a sandboxed frame from a small server on 127.0.0.1 with a random port and a token per page, with no access to LU and no network unless you allow it for that page. Desktop only
  • Large text fields and an editor (issue 197) for persona prompts, reminders and memory, with search and a character and token count
  • Custom sampling parameters (issue 198) by name, type and value, in the persona or in the chat's sampling popup
  • Enter key setting (issue 202): Enter sends, or Enter makes a new line and Ctrl+Enter (Cmd+Enter on a Mac) sends
  • Why the first answer takes so long. When a local Ollama model waits more than 10 seconds before its first word and part of it runs on the processor, the chat says how much fits on the graphics card and names a smaller installed model that would answer faster
  • Right-click "Copy text" copies plain text, and "Copy as Markdown" is the new entry for the source. The message field fits a 375 px wide window, long words and links wrap inside the bubble, and a prompt longer than the context window says so

Create and Animate

  • Long local videos up to 15 seconds, held to the first section. Each new section is matched to the first one in colour, contrast, saturation and sharpness. The whole clip also no longer grows brighter with every section, because it is not encoded again each time. In a 30 second test run the brightness stayed within one step
  • End image and reference pictures in Animate. Locally, an end image for Wan 2.2 A14B image to video, Wan 2.1 FLF2V and MiniMax H3, and up to nine reference pictures for MiniMax H3 reference to video. In LU Cloud, an end image for the models the server offers it for. Models that cannot do it say so
  • Reference pictures in Create. Krea 2 takes up to three pictures for its style, Qwen-Image 2.1 up to ten and FLUX.2 up to four, for a person, a pose, an angle or a style
  • A rough preview while a video renders, so you can stop early if it goes the wrong way
  • Give memory back after a render. Settings, Hardware, "After a render" frees graphics memory and RAM after 5 minutes without a new render, right away, or never
  • LoRAs in the order they run, kept per task and model, with strengths from -2 to +2 (and up to ±20 typed in). A video LoRA no longer stays on when you switch to Image, and the gallery shows which LoRAs made a picture
  • Samplers by the names people use, such as DPM++ 2M SDE, Euler a and Karras, with ComfyUI's own name beside them
  • Edit strength for Qwen-Image edits works now. Before 3.0.8 the slider's value never reached the workflow. Below 1.0 the edit starts from your picture; at 1.0, the default, it comes out as before
  • Details for installed models and LoRAs: type, size, folder and date. A model or LoRA downloaded from now on remembers its Hugging Face or CivitAI page
  • Select several pictures and videos in the gallery (desktop) and move, download or delete them together
  • Gallery folders no longer empty themselves. The gallery kept at most 200 entries, and every new picture pushed the oldest one out, sorted pictures too. Now a picture in a folder is never removed automatically, and the limit counts only unsorted pictures. Folders and prompts lost before 3.0.9 cannot be brought back; the files themselves are still in your output folder
  • Improve my prompt works in Edit too, a prompt assistant turns a few keywords into a prompt for the picked model, a local Edit makes as many pictures as the batch size says, and Qwen Image 2.1 Turbo runs its own 8 step schedule. Comfy-Org's LTX 2.5 image to video template imports and runs (issue 196)

Trainer

  • Train a style, a concept or a pose next to a character (Beta). Train new has a Character | Style / concept switch. The style mode captions by content, has its own steps and turns the result on in the LoRA stack
  • Local training uses the full LoRA strength: LU now passes the network alpha equal to the rank
  • Train new on Windows and Linux says "Local training uses Z-Image" instead of offering image models the local trainer cannot use (issue 210)
  • The trainer setup updates pip first, finds your Python again when a leftover PYTHONHOME or PYTHONPATH got in the way, and writes every skipped Python to the log

Models

  • "Use this model" on Hugging Face opens LU. The link shows repo, file, quant and size, and the download starts only after you click, through the same path as a Discover card with its checksum. Links are checked strictly and anything else is refused
  • A quant that fits your graphics card (issue 215). For a search result that names no quant, LU used to fetch Q4_K_M whatever its size. Now it takes the largest quant that fits in graphics memory with room for the context and says so. A file you named yourself is never swapped
  • "Could not determine model directory" is gone. Every GGUF download from Discover failed with it when another OpenAI-compatible server was set up in LU. Such a model now goes to the LU Engine
  • Remove refusals shows size, percent, speed and time left for every download, and its knowledge check asks 1000 questions. A split GGUF set with parts missing is not downloaded, and the CivitAI search loads small still previews

Agent, MCP and ComfyUI

  • MCP servers with uvx start on Windows, a missing uv says how to install it, and a first start says "Installing server dependencies …" while it downloads. A Mac LU started from the Finder finds uvx and npx
  • PyTorch installs with an old pip (issue 211): LU updates pip first
  • Model files already on disk are not offered again (issue 209). Create says "Your model files are already here" and offers "Start ComfyUI"
  • ComfyUI is no longer started without being asked. LU connects to a running ComfyUI, starting one at launch is a setting, and Comfy Desktop on port 8000 is found
  • REA on Apple Silicon says which Ghidra it uses and whether its decompiler is built for this Mac

Menu bar and tray

A status menu sits in the Mac menu bar and the Windows and Linux tray. With LU Cloud it shows your plan and the credits left. Locally it names the engine, the loaded model and whether it is ready, and the memory in use. Both have Open LU and Quit LU, and the lines stay current while LU runs.

Linux, phone, Windows and updates

  • The Linux AppImage starts again on systems where the tray library cannot be loaded (issue 204, issue 208). If one still fails, LU starts without a tray icon. A 3.0.8 AppImage that does not start cannot update itself, so please download 3.0.9 by hand
  • Windows: no more "Could not find the WebView2 Runtime" after setup. The installer carries Microsoft's WebView2 setup and installs the runtime when it is missing
  • Android: the keyboard stays open on Create. It closed after every tap into the prompt field on many phones
  • Updates are bound to their version. The updater checks that a signed update is the version it claims, and an update you dismissed stays dismissed after a restart
  • "Continue on phone" says where a shared chat shows up: chats shared from the desktop come with the next LU phone app

What we have not tested

The release notes on GitHub have the full list. These are the points to know before you rely on something:

  • Most of this release was clicked through in builds made like the release on a Mac. On Windows a test build ran on an RTX 3060 (12 GB)
  • LFM3 in LM Studio has not been run, and on a Mac only the LFM3 1.7B MLX build has. The LU Engine with b11960 ran text, pictures, dictation and read aloud on a Mac, text and pictures on Windows, and on Linux automated tests only
  • Long videos of 15 and 30 seconds ran on one RTX 3060 with Wan 2.2 A14B. A local end image rendered with Wan 2.2 A14B; reference pictures and the LU Cloud end image have not rendered on a graphics card yet
  • Style training is Beta: in our test a woodcut style was not learned at 600 steps, and photos of real people were not measured
  • Picking a quant by graphics memory ran on Windows and on a Mac, but every test download was stopped at the start, so no swapped model has been run to the end. The fix for "Could not determine model directory" ran on a Mac only
  • The status menu was clicked through on a Mac. On Windows the tray showed the right memory figure, but its entries have not been clicked there yet. On Linux without a loadable tray library there is no status menu
  • The AppImage fix ran in containers on Arch, Ubuntu and Fedora; a tray icon on a real Linux desktop has not been seen
  • If LU installed your ComfyUI before 3.0.9, it no longer starts by itself when LU opens. Turn on "Start ComfyUI when LU starts" in Settings, ComfyUI once, or just generate something in Create
  • Recall works only in the plain chat, not in Agent or Code
  • The Windows installers of this release are not code signed, so SmartScreen and some antivirus engines can warn about them. Is Locally Uncensored safe? explains the warning and how to check a download

How to Steer a Local LLM With Neuron Sliders

Steering changes how a model answers by pushing on its inner activity while it writes. Your prompt stays the same and the weights on disk stay the same. Locally Uncensored has this as a plugin called Neurons: sliders such as Serious to Cheerful, your own sliders made from a few example lines, and a before and after on the same question.

This guide covers what each part does, how to use it, and where it stops working.

The short version

Turn on Neurons under Plugins in Chat, Agent or Code. Pick a model in the LU Engine, move one slider to about 0.5, and run Compare. At 0 the model is exactly as it was.

What Steering Is

A model passes your words through many layers. Each layer holds a long list of numbers, and some directions in that space line up with traits like formal or cheerful. Steering adds a small amount of such a direction while the model generates. LU does this with control vectors, which llama.cpp supports directly.

MethodWhat changesCan you undo it?
System promptThe text the model readsEdit the text
SteeringInner activity while it writesSlider to 0
Fine-tune or LoRAThe weights, through trainingRemove it or go back to the original
AbliterationThe weights, by removing a directionGo back to the original

Turn It On

  1. Open Plugins in Chat, Agent or Code and switch on Neurons. A window opens next to your chat.
  2. Pick a chat model that runs in the LU Engine. If you have none, download one or add a GGUF file from your drive.
  3. The first time, a five-card introduction explains the idea. You can skip it and bring it back later.

Models in Ollama, LM Studio and the cloud do not work here, because those programs take no control vectors from LU. To steer one of them, load the same model in the LU Engine.

Ready-Made Sliders

Among them:

Sober          <->  Creative
Concise        <->  Detailed
Formal         <->  Casual
Serious        <->  Cheerful

A direction from one model means nothing in another, so LU computes each slider on your model the first time you use it. It reads short example pairs through the model, then measures how far it can push before answers break. That takes seconds on small models and a few minutes on large ones. The chat pauses meanwhile, and if a run will take longer than two minutes, LU says so first.

The scale runs from -1 to +1. LU places ±1 just under the point where the measured answer started to break.

Your Own Slider From Examples

Under Add slider, write a few lines for "more like this" and a few for "less like this":

More:  Talk like a pirate.
       Say arr and matey.

Less:  Talk in plain modern English.

Three to ten lines per side are plenty. Keep both sides alike except for the trait, or the slider picks up the other differences too. Models under 1B show traits weakly, and something as specific as a pirate voice needs a bigger model.

Features: Search What the Model Knows

A sparse autoencoder splits one layer's activity into thousands of features. Turning a feature up adds its direction to that layer. LU uses Google DeepMind's Gemma Scope 2 (CC-BY-4.0), so features exist for four models:

Gemma 3 270M IT   layer 9    16k features
Gemma 3 1B IT     layer 13   16k features
Gemma 3 4B IT     layer 17   16k features
Gemma 3 12B IT    layer 24   16k features

Search a word like ocean, or a number like #1234. Each feature is named by the ten tokens it pushes most. Some read clearly and many do not, and LU does not invent labels for them. It downloads only the parts it needs from the official files and checks each one against a pinned SHA-256.

Coordinates: Share a Mix in One Line

Your sliders can be copied as a short line or a link. Paste someone else's under Add slider, Coordinates.

@cheerful+0.5     ready-made slider, works on any supported model
F11690+0.8        feature 11690 of the model's autoencoder
L13N7956-1.0      layer 13, MLP neuron 7956, pushed down by 1
13:7956:-1.0      the same neuron, another common notation

A line can name its model, as in Qwen3.5-4B: L13N7956-1.0 L14N8949+1.0. Feature and neuron numbers belong to one model, so LU tells you which values can run on yours and why the others cannot. Using a recipe replaces your current sliders, and you can undo it.

LU reads only numbers and example sentences from a recipe, never files, addresses or commands. Anything that does not fit the format is refused with the reason.

Single neurons need a model with a fixed feed-forward layer. In a mixture-of-experts model each word goes through a few of many experts, so a neuron has no fixed place and LU says so. Neuron doses go up to ±3, but shared recipes stay within about ±1.2, and ±3 already wrecks any model.

Compare Before and After

Compare asks one question twice, with the sliders off and on, using the same seed at temperature 0. The two answers appear side by side, so the difference comes from the sliders. The engine restarts twice for this. Use it every time you change a mix.

Settings That Hold Up

SettingWhat to expect
One slider up to ±0.75The normal working range
Agent and Code tasksStay around ±0.5
Any slider above ±0.75, or a total above 1LU warns: stronger effect, more odd or repeating text
A total above 1.5LU warns: answers may fall apart and agents may stop following the task

Sliders are saved per model and survive a restart. A persona can have its own set, which wins over the model's. In a group chat the model's sliders apply to every speaker.

Limits

  • LU Engine only. No Ollama, LM Studio or cloud models.
  • Not every model. A few architectures are excluded and LU refuses them. Embedding models cannot be steered.
  • Originals work best. On a model that was changed before, such as an abliterated or merged one, sliders may come out weaker or fail. LU warns you and can point to the original.
  • A change is a restart. llama-server cannot swap control vectors while it runs, so each change takes a few seconds.
  • Steering shifts behavior. It adds no knowledge and no skill the model did not already have.

FAQ

Does steering change the model file?

No. The direction is applied while the model runs. Put the slider at 0, or turn Neurons off under Plugins, and the engine runs without it.

Do tools still work with Neurons on?

Yes. The sliders act inside the model and not on the tools. At high strength a model can lose track of its task, so keep Agent and Code around ±0.5.

Can I steer a model in Ollama or LM Studio?

No. Those programs take no control vectors from LU. Load the same model in the LU Engine instead.

Which models have searchable features?

Gemma 3 270M, 1B, 4B and 12B IT, through Gemma Scope 2. Ready-made and own sliders work on other supported LU Engine chat models as well.

Are shared coordinates safe to paste?

LU reads only numbers and example sentences from them, never files, addresses or commands. A strong recipe can still make a model's answers worse, so check it with Compare.

Kimi K3.1 Pro: What It Can Do, and How to Use It in LU Today

Moonshot AI released Kimi K3.1 Pro on October 23, 2026. It is the post-trained successor to Kimi K3: the same 2.8 trillion parameter model, trained further for long coding sessions and agents that work through many steps. Since October 24 it is in LU Cloud, so you can use it in Locally Uncensored on the desktop, in the browser and on your phone. Running it on your own machine has to wait for the weights, and even then the numbers below apply.

Short version

2.8T parameters, about 104B active per token, 1M token context, text and image input, native tool calls. Fourth on the Artificial Analysis Intelligence Index with 55 points. In LU Cloud on every plan and every credit pack, in Chat, Agent and Code. Open weights are promised by November 4. Not local yet.

What Changed From Kimi K3

The architecture did not change. K3.1 Pro is still a mixture of experts with 2.8 trillion parameters, of which about 104 billion work on each token, and a context window of one million tokens. What changed is the training on top of it, and that shows most in agent work.

On the Intelligence Index only Claude Opus 5.5 (58), Claude Sonnet 5.5 (56) and Muse Wonder Full (56) score higher. On Terminal-Bench 4.0 Artificial Analysis measured the highest score of any model so far. Moonshot's own figure for that test is 65.7%, just behind Opus 5.5 at 66.4% by Moonshot's count. Once the weights are out, it will be the highest scoring open weight model on the index.

Two more things from the launch. Moonshot says it removed cyberattack related material from the training data before the open release, and its own exploit test dropped from 90.5% for the version without that cut to 81% for the released model. And there is a Highspeed variant on Moonshot's own API, two to three times faster at twice the price. LU Cloud carries the standard model.

What It Is Good At

  • Coding agents. Long sessions in a repository: read the code, plan, edit, run the tests, fix what broke. This is where the jump from K3 is largest.
  • Agents with many steps. Native tool calls, so the model calls web search, files and commands directly, with no prompt translation in between.
  • Long input. One million tokens of context fits a large codebase or a stack of documents in one conversation.
  • Images. Screenshots, diagrams and photos as input, next to text.

It reasons before it answers by default. You can switch the thinking off for short questions, and that switch really stops the reasoning on this model.

How to Use It Today in LU

K3.1 Pro runs in LU Cloud, the hosted side of LU, on the same account everywhere. Every plan and every credit pack reaches it; the smallest way in is a 15 EUR credit pack with no subscription.

In the desktop app

In Locally Uncensored 3.0.7 on Windows, Mac or Linux, sign in under Settings, General, LU Cloud Account. Click the Cloud switch in the header twice, and the model picker shows the hosted models. Pick Kimi K3.1 Pro there. It works in Chat, in Agent mode and in the Code tab. The list comes from the server, so you do not need an update for it. One click on the switch brings you back to your local models.

In the browser

Open lu-labs.ai, sign in, and pick Kimi K3.1 Pro in the model picker. Nothing to install, and it works the same on a Mac, a Chromebook or an old laptop.

On your phone

On Android, the LU app reaches LU Cloud with your account, and K3.1 Pro is in its list of hosted chat models. On iPhone the app is in review; until it is out, lu-labs.ai works in Safari.

The step by step version for all three, with the settings that matter in Agent and Code, is in the guide How to use Kimi K3.1 Pro in LU.

What It Costs

K3.1 Pro is the priciest model in the LU Cloud catalog per token, about 5 percent above Kimi K3. It draws 0.3 credits per input token and 1.5 credits per output token, so 300,000 credits per million tokens in and 1,500,000 per million out. Parts of a prompt that repeat, such as the history of a long chat, are billed at a tenth of the input price. A 15 EUR pack carries 450,000 credits.

Thinking tokens are output tokens. On a question that does not need reasoning, switch Think off or set the effort to Low; that is the largest lever on the bill. For volume work a cheaper model in the same picker does the job.

Can You Run It Locally?

Not yet. Moonshot has announced the weights for November 4, 2026, and until they are published there is nothing to download. After that, the honest answer for a desktop is still no, for the same reason as with K3.

K3.1 Pro has the same architecture and size as K3, so the K3 conversions are a fair guide to what to expect:

Build (as for Kimi K3)Size on diskWhat it needs
1-bit GGUF (UD-Q1_0)466 GBMore memory than a 512 GB Mac Studio leaves free, once the context is counted
1-bit GGUF (UD-IQ1_S)594 GBA server with 768 GB of RAM, or two linked 512 GB machines
2-bit GGUF (UD-Q2_K_XL)861 GBA server with about 1 TB of RAM
4-bit (Q4)about 1.5 TBA multi GPU server

The context comes on top of that. And the mixture of experts saves compute, not memory: all 2.8 trillion parameters have to be loaded, because any of them can be needed for the next token.

Speed follows memory bandwidth. At 2 bits, the 104B active parameters mean roughly 30 GB read per token. With the whole model in memory at 800 GB/s, the bandwidth of the fastest unified memory machines, that is a ceiling of about 25 tokens a second; a dual socket DDR5 server lands well below that. Real runs reach a fraction of the ceiling. For comparison, LU Cloud served it at about 55 tokens a second in our test.

A coming version of LU lists K3.1 Pro in the Model Manager once a loadable GGUF is published and the built-in engine reads the Kimi K3 architecture. The bundled llama.cpp does not read it yet, so the entry stays hidden until both are true. The full arithmetic for K3 is in Can you run Kimi K3 locally.

Questions

Is Kimi K3.1 Pro open source?

Not yet. Moonshot has promised the full weights by November 4, 2026. Today it is available through APIs only, including LU Cloud.

Does K3 stay in LU Cloud?

Yes. Both models are in the catalog. K3.1 Pro takes K3's place as the recommended flagship.

Which plan do I need?

Any of them. Every plan and every credit pack reaches the whole chat catalog, K3.1 Pro included.

Can I call it from my own code?

Yes. Create an API key under Cloud API keys on lu-labs.ai, point any OpenAI compatible client at https://lu-labs.ai/api/inference/v1 and use the model id moonshotai/Kimi-K3.1-Pro.

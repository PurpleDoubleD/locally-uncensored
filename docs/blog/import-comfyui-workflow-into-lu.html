Import a ComfyUI Workflow and Run It Without the Node Graph

You have a ComfyUI workflow that does what you want, and you would rather not open the node graph every time. Locally Uncensored 3.0.7 imports workflows in the format ComfyUI saves, installs the node packs they need and lets you change every setting of the workflow from Create. This tutorial goes through it step by step, with the button names as the app shows them.

Windows and Linux only

Workflows run on ComfyUI, which LU installs and starts for you on Windows and Linux. A Mac runs no ComfyUI workflows. Our check in the real app ran on one Windows machine.

What You Need

  • Locally Uncensored 3.0.7 on Windows or Linux, in local mode
  • ComfyUI installed and running. Settings, AI Backends, ComfyUI (Image & Video) has the buttons Install ComfyUI and Start
  • A workflow as a .json file from ComfyUI

Step 1: Save the Workflow in ComfyUI

Use Save, Export or Save (API Format). Until 3.0.6, LU only took Save (API Format). Now a normal save works too, and LU converts it with the node definitions of the running ComfyUI, so ComfyUI has to be started while you import. If it is not, the import says so: "ComfyUI has to be running to import a workflow saved in the regular format, because the node settings are read from it."

Reroute and Primitive nodes are resolved, notes and muted nodes are left out, and bypassed nodes pass their input through. Subgraphs are unpacked the way ComfyUI unpacks them, so the stock templates built on subgraphs, all Z-Image templates among them, can be imported. A workflow with the older group nodes, unknown nodes or settings that do not fit the installed node version is turned down with the reason.

Step 2: Import One File or a Whole Folder

Open Create. Among the controls of the tab sits a workflow button. On Video, Animate and Motion Control it reads "Use your own ComfyUI workflow". On the other tabs it is a small icon titled "Workflows and tags". It opens the window Workflows & tags.

Under "Install a workflow" you have three ways in:

  • Choose files picks one or several .json files at once
  • Choose folder imports every .json in a folder
  • Paste the JSON into the box and click Install pasted workflow

With several files, each workflow is named after its file and gets its own result line, under a count such as "Imported 3 of 4". Importing again under the same name updates the workflow in place and keeps its tags.

Step 3: Install the Node Packs It Needs

When ComfyUI does not know a node of the workflow, a box "Missing node packs" appears. For every node whose pack LU knows, it offers the install right there. Before that it warns: "A node pack is code written by its author. Once installed it runs inside ComfyUI with the same access to this computer as ComfyUI itself, so install only packs you trust." After the install, click Restart ComfyUI and import the workflow again.

For a node LU cannot place, the box names the node, and Open node packs takes you to the section below.

The node pack manager

Settings, AI Backends has a section ComfyUI node packs. It lists every pack in your custom_nodes folder with where it came from, its branch, commit and date, and marks switched off packs as Disabled.

  1. Paste a link into Install from a Git link. LU takes https links to a repository on github.com, gitlab.com or codeberg.org
  2. Click Install. A card repeats the note and says: "LU clones the repository and installs its requirements.txt into the Python of your ComfyUI."
  3. Confirm with the second Install button. The log runs on screen
  4. Click Restart ComfyUI so it loads the new nodes

Update pulls the newest version; a pack LU pins to a tested version stays on it. Remove moves the folder to the trash, nothing is deleted for good. A ComfyUI on another machine is not managed from here.

On Windows we installed a pack from GitHub in the app, ComfyUI knew its nodes after Restart ComfyUI, and Remove put the folder in the Recycle Bin. Update has run in automated tests only.

Step 4: Pair the Workflow With a Model

A tag pairs a workflow with a model. Create one on the Tags view, for example the model family the workflow was built for. Give it to the workflow on the Workflows view and to a model on the Models view.

Then open Advanced settings in Create, the sliders next to the Create button. The Workflow selector lists every workflow whose tags match the current model. Pick yours instead of Auto, and the next render runs through your graph. LU still puts in your prompt, size, steps and seed. Auto brings back the built-in graph.

Step 5: Change Any Setting From Create

With your workflow picked, Advanced settings shows Workflow parameters: each node with its values, such as the VAE, CLIP skip, LoRA strength, denoise or any value of a custom node.

  • Numbers keep the limits ComfyUI states, and lists offer the choices ComfyUI has
  • What LU sets on its own (prompt, seed, size, steps, CFG, sampler, scheduler and model) is named on its node and not offered twice
  • The VAE and the text encoder stay on Auto until you pick one
  • Nodes fold, and Search by name finds a setting

Changes are kept per workflow and go into every run, and Reset goes back to the values in the file. On Windows we changed the denoise of an imported workflow in the app, the run used it, and Reset brought back the value from the file.

Your Own Workflow in Motion Control

Until 3.0.6, Motion Control always ran LU's own graph. Now a workflow imported in the Workflows window and paired with a Wan Animate model runs there. LU fills in the model, the prompt, the seed, the character picture and the driving video, and leaves everything else as you saved it.

The import reads the model from a GGUF loader and the clip from Load Video or Video Helper Suite's Load Video, and files the graph under the Wan Animate family, so the Workflow selector finds it for a Motion Control model. We checked this with tests on QuantStack's Wan 2.2 Animate example workflow, not yet in a real run against ComfyUI.

Add a LoRA From a CivitAI Link

Models, LoRAs, Get new has a card Add a LoRA from a link. Paste a CivitAI model link, with or without a version (without one, LU takes the newest), or a Hugging Face link to a .safetensors file, and click Check link.

Before anything is downloaded, LU reads the file name, the base model and the size from the site, with your CivitAI API key from Settings when one is set. The download runs with progress and Cancel, is checked against its SHA256 when the site states one, and lands in ComfyUI's models/loras folder, where the LoRA stack in Create finds it.

A checkpoint, embedding, VAE or other model that is not a LoRA is refused. When LU does not know the base model, it says so first and the button reads Download anyway. A file of the same name in the LoRA folder is never replaced. On Windows we downloaded a Z Image LoRA from Hugging Face in the app, checked against its SHA256, and a CivitAI checkpoint was refused.

Check Files and Repair

In Models, Get new, image and video bundles have a Check files button once any of their files is on disk. It compares every file with the catalog by size, and by SHA256 where the catalog lists one. Each file reads OK, Missing, Wrong size, Checksum mismatch, Incomplete download or Not confirmed. Repair downloads only the broken or missing files again. A wrong file goes to the Trash, or the Recycle Bin on Windows, first. Check files and Repair have run in automated tests only.

Limits

  • Windows and Linux only. Older group nodes do not import; export those workflows with Save (API Format)
  • In the app we imported stock templates without subgraphs and made a picture with one. Subgraphs have run in automated tests only: all 205 subgraph templates of the template package unpack without a loose wire, but none has run against ComfyUI yet
  • Your own workflow in Motion Control has not run against a real ComfyUI yet

Questions

Do I still need Save (API Format)?

Only for workflows with the older group nodes. Save or Export works as well, as long as ComfyUI is running.

Is installing a node pack safe?

A node pack is code by its author that runs inside ComfyUI with the same access to your computer as ComfyUI. LU says so before every install. Install only packs you trust.

Can I change settings that Create does not show?

Yes, for an imported workflow: Workflow parameters under Advanced settings lists every node with its values.

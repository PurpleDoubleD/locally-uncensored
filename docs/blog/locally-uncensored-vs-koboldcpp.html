Locally Uncensored vs Kobold.cpp

Published March 30, 2026 · Updated October 19, 2026 · 6 min read

Kobold.cpp is a powerhouse for creative writing and roleplay. Built on llama.cpp, it ships as a single executable with zero dependencies and offers advanced text generation controls that writers love. It has grown well past text, with image, video, speech and music generation in the same file. Locally Uncensored is a native desktop app instead: version 3.0.6 combines LLM chat with image and video generation, a coding agent, an agent with tools and your own MCP servers, and local engines next to optional cloud providers.

If your creative workflow involves visuals alongside text, this comparison gets interesting. Both apps run entirely on your hardware with complete privacy, but they target very different use cases. You also do not have to pick only one: Locally Uncensored detects a running KoboldCpp as one of twelve engines. Here is how the two stack up in 2026.

Where Locally Uncensored Wins

  • Image and video generation: on Windows and Linux the app installs and runs ComfyUI for you, with text to image, editing and inpainting, video, image to video, music and more, and models such as FLUX, Qwen-Image 2.1, Wan and LTX. On a Mac, Create runs on the Mac itself. KoboldCpp generates images and video too, inside its single executable, with stable-diffusion.cpp for images. The difference here is ComfyUI and its workflows against one built-in runtime.
  • AGPL-3.0 license: the same copyleft license family as KoboldCpp, keeping the open source ecosystem strong.
  • Native desktop app: a Tauri-based desktop app instead of a browser tab, with better OS integration and lighter resource usage, similar to its advantage over web-based tools like Open WebUI.
  • Built-in model management: browse and download models directly in the app, with a mark on the ones that fit your hardware and a GGUF search on Hugging Face. KoboldCpp ships no models: you fetch GGUF files yourself or start from its Newbie Templates.
  • Coding agent: it builds a map of the repo, edits only the lines you asked for, shows the diff before it applies anything, and runs your tests. KoboldCpp has an agent of its own that writes and edits code and runs programs.
  • Agent tools and MCP: web search and fetch, file operations, a shell, code execution, screenshots and image and video generation, with your own MCP servers on top. KoboldCpp supports MCP servers and web search as well.
  • Thinking mode: the model's reasoning is shown as it happens, with an effort control on the models that offer one. KoboldCpp has thinking tag settings for reasoning models as well.
  • Permissions: every tool call passes a permission gate you control, and a read only run stays read only.

Version 3.0.6 also brings document chat with a local index, group chats where each model can play its own persona, phone access over your LAN or a tunnel, side by side model compare and a local benchmark, and two beta features: Voice, a spoken conversation run on your own machine, and computer control, which is off until you switch it on.

What Locally Uncensored 3.0.7 adds

Version 3.0.7 brings Locally Uncensored closer to KoboldCpp, and lets the two work together:

  • Several local servers at once: KoboldCpp, LM Studio, a llama.cpp server or any other OpenAI compatible backend each get their own row in Settings, AI Backends, and their models sit in the picker under that name. Adding one no longer pushes another out, and a group chat can mix models from several of them. The context window comes from each server itself. So far this has run in automated tests only, not yet in the app with two real servers.
  • Reasoning effort for local models: the Low, Medium, High and Max button next to Think now works on the LU Engine, on LM Studio 0.4.8 and later, on KoboldCpp (Low to High) and on a llama.cpp server whose chat template reads it. It is one setting for all models, and it has run in automated tests only, not against a real LM Studio, KoboldCpp or llama.cpp server. A separate think budget in tokens works with the LU Engine and with Anthropic.
  • KoboldCpp context length: when KoboldCpp behind its Ollama API names no context length, Locally Uncensored now asks KoboldCpp itself instead of holding the model at 4K. Tested with recorded server answers, not yet against a running KoboldCpp.
  • Character cards: a card as PNG or JSON (versions 1, 2 and 3) becomes a persona with the card picture. A new chat opens with the card's greeting, alternate greetings switch with arrows, and a card persona exports back as a version 2 JSON file. Checked in the app with Holo and Qwen models, not with Gemma.
  • Sampling per persona: a persona can carry its own temperature, top P, top K, min P, max tokens, repeat, presence and frequency penalty and DRY multiplier, also on its seat in a group chat. Values set in the chat still win, and each value only goes to a backend that reads it. Automated tests only so far.
  • Duplicate and branch: Duplicate chat copies a conversation with its persona and settings, Branch from here starts a new chat from any message, and Regenerate keeps the earlier answer as a version you can switch back to. These have run in automated tests only.

The Settings, Local API page still reaches only the LU Engine, Ollama and LM Studio. Our check of 3.0.7 in the real app ran on one Windows machine.

Where Kobold.cpp Wins

  • Creative writing tools: story mode, adventure mode, and advanced generation parameters make it a strong tool for fiction writing and roleplay. KoboldAI Lite adds memory, world info, author's notes, characters and scenarios.
  • Zero-dependency setup: a single executable, no installer needed. Download and run.
  • More media in one file: speech recognition with Whisper, text to speech and music generation run from the same executable.
  • Third-party UI compatibility: works as a backend for SillyTavern and other popular frontends, giving you flexibility in your UI choice. The KoboldCpp wiki has its own section on SillyTavern. Locally Uncensored can serve other tools too, through its Local API.
  • Advanced generation controls: fine-grained control over temperature, top-k, top-p, repetition penalty, mirostat, and many more parameters that power users demand.
  • Roleplay ecosystem: KoboldAI Lite imports Tavern character cards from files or external sites, and persistent story saves keep long projects together.

The Verdict

Choose Kobold.cpp if you are focused on creative writing, roleplay, or interactive fiction and want the most advanced text generation controls available.

Choose Locally Uncensored if you want a native desktop app that sets up ComfyUI for images and video, a coding agent that shows its diff first, agent tools with a permission gate, vision and the choice between local engines and cloud providers under one roof. It is especially useful if your creative workflow combines text and visuals, and it can sit on top of a KoboldCpp you already run.

What this page says about KoboldCpp comes from its official GitHub README and wiki, as of October 2026.

Frequently Asked Questions

Is Locally Uncensored better than Kobold.cpp for creative writing?

No. Kobold.cpp is purpose-built for creative writing with story mode, adventure mode, and advanced generation parameters. Locally Uncensored is better if you want text chat combined with image and video generation in one app.

Does Kobold.cpp support image generation?

Yes. KoboldCpp generates images through its built-in stable-diffusion.cpp, with models such as SDXL, SD3, Flux and Qwen Image, and video with models such as WAN 2.2 and LTX 2.3. Locally Uncensored takes another route: it runs ComfyUI on Windows and Linux for image models such as FLUX and Qwen-Image 2.1 and video models such as Wan and LTX.

Can I use Kobold.cpp with SillyTavern?

Yes. The KoboldCpp wiki explains how to run SillyTavern on top of it. Locally Uncensored can also serve other apps: Settings, Local API starts an OpenAI compatible server on your machine, port 8129 by default, that lists the models of the LU Engine, Ollama and LM Studio under one address. It listens on localhost unless you allow the LAN and always asks for a token, so any tool that talks to OpenAI can use it. The other way round works too: since 3.0.7, Locally Uncensored can run a KoboldCpp next to LM Studio or the LU Engine as one of several backends, so far checked in automated tests only.

Which is easier to set up?

Kobold.cpp ships as a single executable with zero dependencies: download and run. Locally Uncensored is an installer with a first-run wizard that finds an engine you already run, or installs one with a single click, and does the same for ComfyUI. Both are straightforward, but Kobold.cpp has fewer moving parts.

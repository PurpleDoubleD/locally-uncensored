Locally Uncensored vs LM Studio

Published March 29, 2026 · Updated October 19, 2026 · 5 min read

LM Studio is one of the most polished local AI apps available, a native desktop client that makes running LLMs feel effortless. Locally Uncensored takes a different approach: an open source desktop app that combines chat with image and video generation, a coding agent and an agent with tools.

Both apps let you run AI models locally without cloud dependencies. The question is what matters more to you: polish and simplicity, or features and freedom. They also work together: Locally Uncensored detects a running LM Studio, uses its server and can link the models it already stores.

Still deciding between the two usual starting points? LU Labs has an Ollama vs LM Studio comparison that covers setup effort and who each one suits.

Where Locally Uncensored Wins

  • Open source (AGPL-3.0): you can inspect, modify, and redistribute the code. LM Studio is closed source.
  • Image and video generation: LM Studio lists no image or video generation. Locally Uncensored generates images with models such as FLUX, Juggernaut XL and Qwen-Image 2.1 and video with Wan, HunyuanVideo and LTX, through a ComfyUI it installs for you on Windows and Linux. On a Mac, Create runs on the Mac itself.
  • Answers directly, abliterated models available: pick a model with the refusal behaviour removed from the weights, or a mainstream one, in the same picker. Nothing sits between you and the model on your own machine.
  • 25 personas: pre-built characters ready to go. LM Studio has presets that save your own system prompts.
  • Free forever: AGPL-3.0 licensed, will always be free. LM Studio has a free plan for local models and paid plans for hosted ones.
  • Coding agent: it builds a map of the repo, edits only the lines you asked for, shows the diff before it applies anything, and runs your tests. LM Studio itself has none; its coding agent lives in Bionic, a separate app.
  • Agent tools and MCP: web search and fetch, file operations, a shell, code execution, screenshots and image and video generation are built in, and your own MCP servers add more. LM Studio connects MCP servers too.
  • Multi-provider support: local engines next to OpenAI, Anthropic and other cloud providers with your own keys. LM Studio runs local models and, through LM Link, models on your other machines.
  • Model load/unload: manage VRAM directly from the UI by loading and unloading models on demand. LM Studio loads and unloads models as well, and a load in LM Studio can be cancelled from Locally Uncensored.

Version 3.0.6 also brings document chat with a local index, phone access over your LAN or a tunnel, side by side model compare and a local benchmark, and two beta features: Voice, a spoken conversation run on your own machine, and computer control, which is off until you switch it on.

What Locally Uncensored 3.0.7 adds

Version 3.0.7 adds these points that matter next to LM Studio:

  • Several local servers at once: KoboldCpp, LM Studio, a llama.cpp server or any other OpenAI compatible backend each get their own row in Settings, AI Backends, and their models sit in the picker under that name. Adding one no longer pushes another out, and a group chat can mix models from several of them. The context window comes from each server itself. So far this has run in automated tests only, not yet in the app with two real servers.
  • Reasoning effort for local models: the Low, Medium, High and Max button next to Think now works on the LU Engine, on LM Studio 0.4.8 and later, on KoboldCpp (Low to High) and on a llama.cpp server whose chat template reads it. It is one setting for all models, and it has run in automated tests only, not against a real LM Studio, KoboldCpp or llama.cpp server. A separate think budget in tokens works with the LU Engine and with Anthropic.
  • LM Studio keeps your context size: a size picked for a model is saved and used whenever Locally Uncensored loads it, and a picture or clip no longer starts a closed LM Studio. The context size part was tested with a stand in for LM Studio, not with LM Studio itself.
  • Any GGUF file on your drive: the Model Manager links a GGUF file from anywhere on the same drive into the LU Engine as a chat model, without copying it.
  • Duplicate and branch: Duplicate chat copies a conversation with its persona and settings, Branch from here starts a new chat from any message, and Regenerate keeps the earlier answer as a version you can switch back to. These have run in automated tests only.
  • More of Create on a Mac: Talking Character, Motion Control, Music, Enhance Image, Remove Background, masks in Edit and character training now run on the Mac itself. They ran with the real engine on one Mac with 48 GB; Macs with less memory have not been tried, and the Mac parts have not been clicked through in a built app yet.

The Settings, Local API page still reaches only the LU Engine, Ollama and LM Studio. Our check of 3.0.7 in the real app ran on one Windows machine.

Where LM Studio Wins

  • Polish and UX: LM Studio is beautifully designed with a native feel. Model browsing and downloading is seamless, and its Hugging Face browser is broader for discovering unusual quantizations.
  • Longer track record on the Mac: LM Studio has run on macOS for a long time. Locally Uncensored has had a Mac build only since 3.0.6, for Apple Silicon and as a beta.
  • Performance: llama.cpp and MLX runtimes built into the app, with no second layer between the interface and the engine.
  • Developer API: a mature OpenAI-compatible API server for integrating with other tools. Locally Uncensored has a Local API as well, which can also route to LM Studio's models.
  • Model formats: loads GGUF files directly, and MLX models on Apple Silicon.
  • Tool calls you can edit: LM Studio connects MCP servers and shows each tool call in a confirmation dialog, where you can change the arguments before it runs.

The Verdict

Choose LM Studio if you want the most polished local chat experience with zero setup friction, and you do not need image or video generation. It's the "just works" option.

Choose Locally Uncensored if open source matters to you, if you want image and video generation alongside chat, or if you prefer uncensored models by default. It also has a coding agent, agent tools with MCP, vision, document chat, cloud providers next to local engines, and VRAM management. It does more, you own it, and it can keep using the LM Studio you already have.

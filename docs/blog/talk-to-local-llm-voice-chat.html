Talk to a Local LLM: Voice Chat on Your Own Machine

Since version 3.0.6, Locally Uncensored has a Voice surface. You speak, the chat model you picked answers, and you hear the answer. Speech recognition, the voice and the turn taking run on your own machine. This guide goes through the setup, the first session, the four switches next to the title, and the limits.

Voice is in beta and English only. Our check in the real app ran on Windows. On a Mac it has been tried by hand in the app, and on Linux it has not been run in the app yet. If something is rough on your computer, that is why the word Beta stands next to the title.

What You Need

  • Locally Uncensored 3.0.6 or newer, in local mode. With the Cloud switch on, Voice is hidden, because LU Cloud has no voice service yet
  • A local chat model. Voice has no model of its own. It talks with the one selected in the chat
  • A microphone. A headset helps, for a reason explained below
  • Free disk space for the voice engine. The setup screen shows the exact download size, the space needed and your free space before anything is fetched

If your chat model takes no tools or is smaller than 7B, the empty Voice surface recommends a local model that fits. The chat chapter of the handbook covers the model picker.

Step 1: Install the Voice Engine

Open Voice in the main navigation. The first time, you see a setup screen titled "Talk to your model". It lists three numbers: Download, Space needed and Free space. A line named "What is downloaded" opens the list of parts with the size of each one, and "Stored in" names the folder they go to.

Pick a voice if you like, then click Install. You can cancel while it runs. What was already downloaded is kept, and Continue setup picks up where it stopped.

What gets installed, in plain terms: Whisper base.en for speech recognition and Pocket TTS for the voice, plus the engine that handles turn taking. All of it runs locally after the one-time setup.

Step 2: Pick a Voice

There are fifteen voices: Alba, Anna, Azelma, Charles, Eponine, Eve, Fantine, George, Jane, Javert, Marius, Mary, Michael, Paul and Vera. Choose one in the setup or later in the Voice settings. Changing it fetches one small file and installs nothing else again.

Listen plays a short sentence in the chosen voice once the voice engine is installed. A new voice speaks from the next session on, so stop a running session if you want to compare voices.

Step 3: Start Talking

Click Start. A quiet chord of about a second says that the session is listening. You can switch that sound off in the Voice settings.

The first session after setup or after a restart is slow to start. In our Windows tests it took 23 to 63 seconds cold, against about one second warm. You do not have to wait in silence, though. What you say after the Start click is kept for up to a minute, also while the speech models are still loading, and answered once the session is up.

From there it is a conversation. Ask something, listen, ask the next thing. If the answer runs long or goes the wrong way, speak, and LU stops talking and listens. The microphone button mutes you without ending the session. Stop ends it, and the whole exchange is saved as a normal conversation you can open again in the chat.

A few things to try in a first session:

  • "Explain what a context window is, in two sentences."
  • "Give me three names for a small bakery." Then interrupt after the first one and ask for something shorter
  • "Summarize what we have talked about so far."

Step 4: The Four Switches

Four switches sit next to the title. You can move all of them while a session runs, and the session follows at once.

SwitchWhat it does
Voice settingsVoice, microphone, the start sound, starting with the microphone muted, thinking length, repair and uninstall
AgentOn: Voice can use tools, such as the web, files and commands. Off: a conversation without tools
Where it may workWorkspace only, which is the default, or Whole computer
ThinkingShows the thought in the transcript as a folded Thinking block. Off by default, and never read aloud

Agent: Tools by Voice

With Agent on, a voice session has the tools of the agent chat with the same permissions. A tool call looks the way it does in the chat. When a tool needs your approval, the same approval bar asks in plain words, for example "Voice wants to change a file." You answer it with a click on Approve or Reject. Saying yes does not approve it.

Local models get a shorter tool list in Voice (web, files, shell and the screen), so the first answer comes quickly. If the model cannot use tools, the Agent switch says so.

Requests that fit this mode:

  • "Look up the release date of Python 3.13 and tell me."
  • "Create a file called notes.txt with three ideas for the weekend."
  • "List the files in the workspace and read me the names."

Where It May Work

Workspace only is the default. Files stay inside the folder of the session, LU asks before every command, and there is no screen.

Whole computer opens files by any path your user account can open, commands in any folder, and the screen. LU asks once before that level is used for the first time, in a dialog titled "Let Voice work on the whole computer?". System folders and the folders that hold keys and passwords stay closed at both levels.

The screen part is computer control, which is its own beta feature with its own questions. In every new chat a card asks "Allow computer control in this chat?" and waits for a click. In a voice session LU says aloud that it waits for your click. A spoken yes does not allow it, and a spoken no or stop declines. On a Mac, computer control is in the app but not fully tested yet.

Thinking

Thinking is off by default. Switched on, the thought appears in the transcript and stays silent. Thinking length in the Voice settings limits a thought to between 128 and 4096 tokens, 512 by default. When a thought runs longer, LU ends it and asks the model again for a direct answer.

Free the Memory When You Are Done

While the voice engine is in memory, a switch next to the title shows how much memory it holds. LU measures that number. On our Windows test machine it was about 1 GB. One click ends the session and stops the engine, and if the voice session loaded the chat model, that model is unloaded too. Without the click, the engine shuts down five minutes after the last session.

Use the Same Engine for Dictation

The microphone button in the chat uses the speech recognition of the voice engine if no separate speech-to-text install exists. So once Voice is installed, you can dictate a message in the normal chat as well.

To pick the microphone, go to Settings, Voice & Remote, Speech. The Microphone field lists the system default and your input devices by name, and the choice holds for dictation and for Voice. The names appear once the app may use the microphone. This field is new in 3.0.6 and has run in automated tests, not yet with a real microphone on our side.

Limits You Should Know

  • English only, and the voices are fixed
  • Local mode only. Voice is hidden while the Cloud switch is on
  • Speaking while LU speaks relies on the echo cancellation of your system. With loud speakers and no headset, the first words of an interruption can be quiet or missing
  • For the first six seconds after the Start click, a voice that reaches the microphone only faintly is turned down. A headset is not affected
  • The first session after setup or a restart starts much slower than later ones
  • Only a serious error ends a session, and it says why. Smaller ones go to the log, with one line under the status when you would miss something, for example a sentence that could not be spoken

Questions

Does my voice leave my computer?

Speech recognition, the voice and the turn taking run on your own machine. The answer comes from the chat model you picked, and Voice is shown in local mode only. If you switch Agent on and ask for something on the web, the web tool fetches pages like it does in the agent chat.

Which model should I use?

The one you already chat with, as long as it takes tools and is 7B or larger. Below that, the empty Voice surface recommends a local model that fits.

Can I use Voice in German, Spanish or another language?

Not yet. Voice is English only for now.

Does Voice work on a Mac or on Linux?

The Mac build has Voice, and it has been tried by hand in the app there. It did not go through the point by point check the Windows app got. The Linux packages carry the voice engine, but Voice has not been run in the app on Linux by us.

How do I remove it again?

The Voice settings have an uninstall for the voice engine, and a Repair that checks the packages and every model file and downloads again only what is missing or does not match.
